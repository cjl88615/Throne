TaliabuVPN 绿色版使用说明 / Panduan TaliabuVPN Portable
====================================================

【中文】

一、开始使用
1. 请先把整个压缩包完整解压到一个固定文件夹，不要直接在压缩包内运行程序。
2. 双击 TaliabuVPN.exe 启动。
3. 本版本默认开启 FakeIP、默认勾选 TUN 模式，并默认开启“记住上次的配置档”。
4. 因为 TUN 模式需要系统管理员权限，Windows 可能会显示“用户账户控制（UAC）”提示，请选择“是”。
5. 在 TaliabuVPN 中导入你的订阅或配置档，选择需要使用的配置档后启动连接。
6. 成功使用过一个配置档后，TaliabuVPN 会记住上次使用的配置档；下次启动时会自动恢复上次配置档与 TUN 模式。

二、让 TaliabuVPN 始终以管理员身份运行
如果希望每次双击 TaliabuVPN.exe 时都自动请求管理员权限：
1. 右键 TaliabuVPN.exe → “属性”。
2. 打开“兼容性”选项卡。
3. 勾选“以管理员身份运行此程序”。
4. 点击“应用” → “确定”。

重要说明：Windows 的这个选项只会保证 TaliabuVPN 每次以管理员权限启动，并不能关闭 UAC 确认窗口。因此 Windows 仍可能在每次手动启动时要求你点击“是”。这是 Windows 的安全机制，不建议为了取消提示而关闭系统 UAC。

如果你只是希望开机后自动运行而不需要每次手动双击，可先以管理员身份启动一次 TaliabuVPN，再在软件中启用“开机启动/Start with system”。

三、常见提示
- TUN 模式需要管理员权限，这是正常现象。
- 请勿删除 TaliabuVPN.exe 同目录下的其他文件，它们是程序运行所需组件。
- 如果更换电脑或目录，建议重新完整解压一次绿色版。
- 如果已有旧版配置，旧配置中已经保存的选项会优先于本绿色版的默认值。


【Bahasa Indonesia】

1. Mulai menggunakan
1. Ekstrak seluruh isi ZIP ke satu folder tetap. Jangan menjalankan program langsung dari dalam file ZIP.
2. Jalankan TaliabuVPN.exe.
3. Versi ini secara default mengaktifkan FakeIP, mencentang mode TUN, dan mengaktifkan “Remember last profile”.
4. Karena mode TUN memerlukan hak Administrator, Windows dapat menampilkan konfirmasi User Account Control (UAC). Pilih “Yes”.
5. Impor subscription atau profil konfigurasi Anda di TaliabuVPN, pilih profil yang ingin digunakan, lalu mulai koneksi.
6. Setelah sebuah profil berhasil digunakan, TaliabuVPN akan mengingat profil terakhir. Pada pembukaan berikutnya, profil terakhir dan mode TUN akan dipulihkan secara otomatis.

2. Selalu menjalankan TaliabuVPN sebagai Administrator
Agar setiap kali TaliabuVPN.exe dibuka program selalu meminta hak Administrator:
1. Klik kanan TaliabuVPN.exe → “Properties”.
2. Buka tab “Compatibility”.
3. Centang “Run this program as an administrator”.
4. Klik “Apply” → “OK”.

Catatan penting: pengaturan ini hanya memastikan TaliabuVPN selalu berjalan dengan hak Administrator. Pengaturan ini TIDAK menonaktifkan konfirmasi UAC. Windows masih dapat meminta Anda menekan “Yes” setiap kali program dijalankan secara manual. Ini adalah mekanisme keamanan Windows; tidak disarankan menonaktifkan UAC hanya untuk menghilangkan konfirmasi tersebut.

Jika tujuan Anda hanya agar TaliabuVPN berjalan otomatis saat Windows masuk tanpa perlu membuka program secara manual, jalankan TaliabuVPN sekali sebagai Administrator lalu aktifkan “Start with system” di dalam aplikasi.

3. Catatan umum
- Mode TUN membutuhkan hak Administrator; ini normal.
- Jangan hapus file lain yang berada di folder yang sama dengan TaliabuVPN.exe karena file tersebut diperlukan oleh aplikasi.
- Jika memindahkan aplikasi ke komputer atau folder lain, sebaiknya ekstrak ulang seluruh paket portable.
- Jika Anda sudah memiliki konfigurasi lama, pengaturan yang tersimpan sebelumnya akan tetap diprioritaskan daripada nilai default versi portable ini.
